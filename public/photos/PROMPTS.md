# Image generation prompts

One prompt per horse. Start every prompt with the shared style line so the set looks consistent, generate in portrait (3:4), and save as the file name shown. Use the negative prompt where your tool supports one.

**Shared style line (prefix every prompt):**
Realistic photograph, portrait orientation 3:4, head-and-shoulders portrait of a single horse looking toward the camera, sharp detailed eyes, shallow depth of field, soft natural light, no people, no text, no watermark.

**Negative prompt:**
cartoon, illustration, painting, CGI, extra limbs, deformed face, blurry eyes, people, riders, text, watermark, logo, frame
